픽AI(PICKAI, 이하 “서비스”)는 주식·차트 정보 조회, AI 분석, 오늘의 PICK, 포인트·멤버십, 투자 부적 생성 등의 기능을 제공하는 모바일 앱입니다. 본 방침은 Google Play에 배포되는 픽AI 앱과 이 앱이 이용하는 픽AI API 서버(예: pickai-api.duckdns.org)를 기준으로 작성되었습니다.

2. 처리하는 개인정보와 목적

  • 회원 인증·계정 관리: Google 또는 네이버 소셜 로그인, 세션 유지, 계정 삭제 처리
  • 서비스 제공: 관심종목, AI 분석 기록, 오늘의 PICK 열람, 포인트·멤버십, 투자 부적
  • 유료 결제: Google Play 인앱결제 검증 및 포인트·구독 혜택 반영
  • 보안·부정 이용 방지: 웰컴 포인트 중복 지급 방지(설치·소셜 계정 식별자 해시)
  • 고객 문의: 이메일 등을 통한 문의 대응

서비스는 소셜 로그인 제공자의 비밀번호를 수집·저장하지 않습니다.

3. 회원가입 및 로그인

이용자는 Google 또는 네이버 계정으로 로그인할 수 있습니다. 로그인 시 앱은 픽AI API 서버와 통신하고, 서버는 자체 SQLite 데이터베이스에 계정·세션 정보를 저장합니다(코드베이스상 Supabase·Firebase Auth 미사용).

로그인 과정에서 처리될 수 있는 정보는 다음과 같습니다.

  • 소셜 제공자(Google/Naver), 제공자 사용자 식별자
  • 이메일, 닉네임(표시명), 프로필 이미지 URL(제공·동의한 경우)
  • 서버 발급 세션 토큰(앱 보안 저장소에 보관, 서버에 세션 레코드 저장)
  • 웰컴 포인트 중복 방지용 installationId(앱이 생성·전송 시): 원문은 저장하지 않고 HMAC 해시(installation_id_hash)로 처리할 수 있음

네이버 로그인 이용 시, 회원 탈퇴 시 연동 해제를 위해 네이버 액세스 토큰을 서버에 저장할 수 있습니다.

4. AI 분석·차트 이미지·오늘의 PICK

  • 종목 AI 전망·텍스트 분석: 종목 코드·종목명·시장·시세·캔들·지표 등 분석에 필요한 시장 데이터가 서버를 통해 OpenAI API로 전송될 수 있습니다. 분석 결과 요약은 analysis_history 등 서버 DB에 저장될 수 있습니다.
  • 차트 이미지 AI 분석(이용자가 촬영·선택한 경우): 이미지(base64), 종목·봉 주기·가격 관련 정보가 요청 처리를 위해 서버를 경유해 OpenAI API로 전송됩니다. 코드상 차트 이미지 파일을 서버 디스크에 장기 보관하는 저장 로직은 투자 부적과 달리 전용 영구 저장 경로가 없으며, 분석 결과 텍스트는 분석 기록에 포함될 수 있습니다.
  • 오늘의 PICK: 카테고리 열람 시 포인트 차감·열람 권한 확인을 위해 서버 API(/today-pick/access)를 호출합니다. 포인트 거래·분석 유형 메타데이터가 서버에 기록됩니다.

서버 구현상 OpenAI 요청에 이메일·닉네임·내부 userId·결제 정보를 넣지 않도록 처리합니다(분석 프롬프트·API 계약 기준).

5. 관심종목·분석 기록·로컬 저장

  • 관심종목: 서버 DB favorites에 종목 코드 등 저장
  • AI 분석 기록: 서버 DB analysis_history에 분석 유형·종목·결과 요약·포인트 비용 등 저장
  • 최근 본 종목·일부 캐시: 앱 내부 저장소(AsyncStorage 등)에 로컬 저장될 수 있으며, 서버 DB에 동일 항목이 별도 저장되지 않을 수 있음
  • 로컬 알림: 이용자가 설정한 조건 알림은 기기에서 예약·표시되며, 알림 문구에 종목명 등이 포함될 수 있음(서버 푸시 대신 로컬 알림 사용)

6. 포인트·결제·멤버십

  • 포인트 지갑·거래·예약: 서버 DB(point_wallet, point_transactions, point_reservations)
  • Google Play 인앱결제: 앱은 react-native-iap로 구매 후, 서버가 Google Play Developer API로 검증합니다. billing_purchases에 상품 ID, purchaseToken, orderId 등이 저장될 수 있습니다.
  • 멤버십 플랜: 사용자 레코드의 plan(FREE/PRO) 등으로 관리

코드베이스에서 RevenueCat 등 별도 결제 중개 SDK는 확인되지 않았습니다.

7. 투자 부적(이미지 생성)

이용 시 포인트가 차감되고, OpenAI Images API로 생성된 이미지가 서버 디스크에 사용자별 경로로 저장되며, DB investment_talismans에 이미지 URL·생성 상태·포인트 거래 연결 정보가 기록됩니다.

8. 시세·종목 데이터

금융위원회 등 공개 API·제3자 시세 데이터를 조회합니다. 조회 시 이용자 개인을 식별하는 정보를 시세 제공자에게 전송하지 않는 구조를 목표로 합니다(종목 코드·시장 조회 중심).

9. 자동 수집·로그·분석 SDK

  • 앱 코드에서 Firebase Analytics, Sentry, Amplitude, RevenueCat 등 상용 분석·크래시 SDK 의존성은 확인되지 않았습니다.
  • 서버·운영 환경에서는 오류 대응·보안을 위해 접근 로그, 애플리케이션 로그가 생성될 수 있습니다(구체 보관 기간·IP 수집 범위는 서버·호스팅 설정에 따름 — 운영자 확인 필요).
  • 관리자 기능 사용 시 IP·User-Agent가 관리자 감사 로그에 기록될 수 있습니다(일반 이용자 대상 기능 아님).

10. 앱 권한(Android)

앱 매니페스트에 선언된 주요 권한은 다음과 같습니다(실제 사용 기능에 따라 요청).

  • INTERNET: API 통신
  • CAMERA: 차트 촬영·분석(이용 시)
  • com.android.vending.BILLING: Google Play 결제
  • POST_NOTIFICATIONS: 로컬 조건 알림
  • VIBRATE, SCHEDULE_EXACT_ALARM, SYSTEM_ALERT_WINDOW 등: 알림·예약 알림 관련

매니페스트에서 READ_MEDIA_IMAGES·READ_CONTACTS 등은 제거(tools:node="remove")된 항목이 있습니다. 갤러리 선택 방식은 앱·OS 버전별 구현을 따릅니다.
